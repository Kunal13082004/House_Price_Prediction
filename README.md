# 🏠 House Price Prediction

A simple Machine Learning project that predicts the estimated price of a house based on its features.

## 📌 Project Description

This project uses Machine Learning to estimate house prices using:

- Area (sq ft)
- Number of Bedrooms
- Number of Bathrooms
- Parking Spaces
- House Age

## 🤖 Machine Learning Algorithm

**Linear Regression**

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib

## 📂 Project Files

- `dataset.csv` - House dataset
- `train.py` - Machine Learning model training and evaluation
- `app.py` - Streamlit web application
- `requirements.txt` - Required Python libraries
