# 🏡 Kunal.AI — Advanced House Price Prediction

Advanced city-aware ML project using Streamlit.

### Upgrades
- 6,500 property records across 15 Indian cities
- 17 prediction features
- Random Forest + Gradient Boosting comparison
- Automatic best-model selection
- Animated dark/glass UI with Kunal.AI branding
- Interactive property predictor
- Smart EMI calculator
- City price intelligence chart

### Run
```bash
pip install -r requirements.txt
python train.py
streamlit run app.py
```

**Note:** The dataset is synthetic and intended for learning/portfolio demonstration, not official real-estate valuation.
